EMBERLINE — Dock 9: a round-based tactical FPS in the browser, built on three.js 0.187.0. Vanguard versus four Rustjackal bots on a night container yard: plant the charge at site A or B, or wipe the other team. First to 5 rounds takes the match. Money earned each round buys rifles, a marksman rifle with a scope, a shotgun, an SMG, frags and flashbangs between rounds. Bots patrol routes, hold angles, investigate gunfire, strafe and burst-fire back, fall back when hurt, and rush the planted charge to defuse it. Hitscan gunplay with headshots, recoil and spread that punishes firing on the move, crouching, jumping, and a fixed-step simulation kept apart from rendering. All art is styled geometry and all sound is synthesised in WebAudio — no assets, no network, just static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — click to play. `WASD` move, mouse look, click fire, `R` reload, `1`/`2` guns, `3` frag, `4` flash, hold `E` to plant, `B` buy menu, `Ctrl` crouch, `Space` jump, right-click to scope with the Longbow.
